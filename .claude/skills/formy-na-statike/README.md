# Скилл: formy-na-statike (формы на статике)

Методика создания формы заявки с доставкой писем на статическом сайте
(html/css/js без движка) и проверки её до боевого запуска: инвентаризация
хостинга и почты, выбор схемы отправки (mail()/SMTP/релей), конверт письма,
журнал-страховка, приёмка доставляемости. Универсален: не привязан к
провайдеру. Скилл читает Claude Code при запуске задачи; этот файл —
справка для человека.

## Состав папки

| Файл | Назначение |
|---|---|
| `SKILL.md` | Вход скилла: инвентаризация (этап 0), выбор схемы, конверт, журнал, приёмка, кейсы. Читается автоматически |
| `README.md` | Эта справка; при запуске скилла не читается |

Скилл — вспомогательный компонент скилла kopiya-sajtov (лендинг, полная
копия); вызывается, когда в продукте появляются формы. Самостоятельная
задача «сделать форму» тоже ведётся по нему.

## Перенос в другой проект или компьютер

- Скопировать папку целиком. Проектный уровень: `<проект>/.claude/skills/formy-na-statike/`; пользовательский (все проекты компьютера): `~/.claude/skills/formy-na-statike/`. С учётной записью не синхронизируется.
- Зависимостей от пакетов нет: методика текстовая, обработчики пишутся под целевой сервер (PHP или иной по хостингу).
- Соглашение, на которое опирается скилл: файлы диалогов — `docs/sessions`, отчёты — `docs/reports`. В проекте без такой структуры либо создать её, либо поправить упоминания в SKILL.md.
- Кейсы-примеры упоминают конкретные хостинги — на работу в другом месте не влияют.
