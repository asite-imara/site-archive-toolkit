# Скилл: kopiya-sajtov (копирование сайтов)

Методика снятия сайта и построения на его основе продуктов: полный html-архив,
лендинг из копии, «чистая облегчённая» полная копия на другом домене.
Универсален: не привязан к сайту, хостингу или движку. Скилл читает Claude
Code при запуске задачи; этот файл — справка для человека.

## Состав папки

## Перенос в другой проект или компьютер

- Скопировать папку целиком. Проектный уровень: `<проект>/.claude/skills/kopiya-sajtov/`; пользовательский (все проекты компьютера): `~/.claude/skills/kopiya-sajtov/`. С учётной записью не синхронизируется.
- Требования к окружению: Python 3 со стандартной библиотекой; ничего устанавливать не нужно.
- Соглашения о папках, на которые опирается скилл: отчёты — `docs/reports`, файлы диалогов — `docs/sessions`, временные файлы — `TMP`. В проекте без такой структуры либо создать её, либо поправить упоминания в SKILL.md.
- Кейсы-примеры в SKILL.md упоминают конкретные сайты — помечены «не инструкции к копированию», на работу в другом месте не влияют.
