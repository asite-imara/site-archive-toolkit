## Проблема

Исходный сайт компании прошёл два этапа: сначала работал на Wordpress/WooCommerce, затем дизайн вручную перенесли на ModX Revolution. При переносе в коде осталось много стилей и скриптов от Wordpress, к ним добавились новые от ModX Revo — сайт тянул две системы разом. Страницы дублировались, часть адресов не попадала в sitemap, ссылки вели на несуществующие ресурсы, а перенести сайт на новый домен без полной копии было невозможно. Нужны были точные данные о том, что реально есть на сайте, и самостоятельные копии разделов, не зависящие от движка.

## Пользователь

Проект собран для внутреннего использования маркетинговым агентством: SEO-специалист, ведущий продвижение и техническую поддержку сайтов клиентов на примере промышленной тематики (опорные подшипники, приводные элементы).

## Основная функция

1. Инвентаризация адресов сайта: разбор sitemap, обход всех страниц, сбор мета-тегов и ссылок, проверка доступности каждого адреса и ресурса, классификация страниц по типам.
2. Статический лендинг (поддомен kirov) с приёмом заявок: самостоятельная HTML-копия без движка, форма заказа с отправкой почты по SMTP и журналом заявок в CSV, цели Яндекс.Метрики.

## Формат результата

- CSV-реестр всех страниц сайта с типами, заголовками и статусами; отдельный CSV битых ссылок; markdown-сводка по типам страниц.
- Готовая к размещению на хостинге папка статического лендинга (HTML, CSS, JS, изображения) с обработчиком форм на PHP.

## Минимальный функционал

- `scripts/` — четыре скрипта на Python: разбор sitemap, обход страниц, проверка ссылок, сборка CSV-отчётов.
- `.claude/skills/` — два скилла для Claude Code: `kopiya-sajtov` (копирование сайтов: архив, лендинг, полная копия, со скриптом выгрузки) и `formy-na-statike` (формы и почта на статике).
- `kirov.prom-opora.ru/` — лендинг: страница, обработчик форм (SMTP, журнал заявок, защита от спама), цели Метрики, сборочные скрипты.
- `docs/reports/` — отчёты и планы по каждой задаче: сборка копий, чистка CSS, настройка почты и Метрики, приёмка.

## Технологии

- Python 3 — скрипты инвентаризации (без сторонних библиотек: urllib, json, csv).
- HTML5, CSS, JavaScript — статический лендинг.
- PHP — обработчик форм (чистый SMTP-клиент на fsockopen + STARTTLS, без библиотек).
- Яндекс.Метрика — счётчик и цели.

Примечание: пароли и адреса почты в коде заменены заглушками; при использовании подставьте свои значения в начале `form-handler.php`.
