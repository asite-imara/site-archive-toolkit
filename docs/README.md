## Правила ведения

- Единица работы: одна сессия = одна задача (начальный промпт). Если задача не влезает в контекст — разбить на сессии-этапы, каждая со своим диалогом и отчётом.
- Завершённая задача → отчёт report-<тема>-<дата>.md в reports/.
- Изменения в планах → обновить plan-prom-opora-<дата>.md или создать новый по дате.
- Нейминг: тип-тема-дата через дефис, без пробелов.
