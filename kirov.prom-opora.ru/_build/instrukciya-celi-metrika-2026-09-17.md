# Инструкция: заведение целей в Яндекс.Метрике для лендинга kirov.prom-opora.ru

Дата: 2026-09-17
Счётчик: [номер счётчика] (вшит в index.html, константа YM_ID — правки страницы больше не нужны).
Перечень целей: goals.csv (CSV с «;») и goals.md (таблица) — в этой же папке.

## Назначение

Лендинг работает как «прокладка» для поисковой рекламы в Яндекс.Директе: трафик из Директа приходит на kirov.prom-opora.ru, ключевое конверсионное действие — отправка формы (цель form_submit), вспомогательные — уходы на каталог и разделы основного сайта prom-opora.ru, звонки и мессенджеры. Цели понадобятся и для настройки статистики в самом Директе (счётчик привязывается к кампании).

## Шаг 1. Открыть настройку целей

1. Зайти на metrika.yandex.ru под аккаунтом, где создан счётчик.
2. Выбрать счётчик [номер счётчика] (Пром-Опора Киров).
3. Шестерёнка «Настройка» → вкладка «Цели» → кнопка «Добавить цель».

## Шаг 2. Создать цель (одна итерация на каждую цель из таблицы)

1. Название — взять из колонки «Куда ведёт» / «Текст ссылки» в goals.md (например, «Каталог: опоры освещения металлические» или «Заявка: отправка любой формы»). Название — только для вас в отчётах.
2. Тип цели: «JavaScript-событие».
3. Идентификатор цели — скопировать из колонки «Идентификатор» в goals.md (например, go_oporyi-cilovyie-sp). Вставлять точно, без пробелов по краям — при опечатке цель никогда не сработает.
4. Сохранить. Повторить для всех 47 целей.

Лимит Метрики — 200 целей на счётчик, 47 помещается с запасом. Пакетного импорта в интерфейсе нет, вручную занимает порядка 20–30 минут.

## Порядок заведения (если делать частями)

Приоритет от главного к второстепенному:

1. Конверсионное ядро: form_submit, go_tel, go_whatsapp, go_viber, go_telegram, go_email — заявка, звонок и мессенджеры.
2. Каталог целиком: go_katalog и категории верхнего уровня (опоры освещения, кронштейны, опоры дорожных знаков, рамные, винтовые сваи, фундаменты).
3. Внутренние страницы каталога — по таблице.
4. Служебные: go_o-kompanii, go_proizvodstvo, go_portfolio, go_dostavka-oplata, go_yamaps, go_politika-konfidenczialnosti.

## Шаг 3. Проверка, что цели срабатывают

1. Открыть сайт с параметром отладки: https://kirov.prom-opora.ru/?_ym_debug=1
2. Открыть консоль браузера (F12 → Console).
3. Кликать элементы страницы: клики по кнопкам каталога, телефону, формам. В консоли при каждом срабатывании появляется строка вида «reachGoal ... goal name ...» с идентификатором цели.
4. Сверить идентификаторы с goals.md. Отправка любой формы даёт цель form_submit.
5. В отчёте «Конверсии» данные появятся в течение нескольких минут (по цели form_submit — после тестовой отправки формы).

## Шаг 4. Связка с Директом (после создания кампании)

1. В Директе счётчик [номер счётчика] указывается в настройках кампании (счётчик привязывается к кампании автоматически по логину Метрики либо добавляется вручную).
2. Ключевая цель для статистики кампании — form_submit; вспомогательные — go_tel и мессенджеры. Внутренние цели go_* нужны для понимания, куда уходит трафик с «прокладки», в оптимизацию Директа их закладывать не нужно.
3. Не назначать слишком много целей ключевыми — статистика размывается.

## Типичные ошибки

- Идентификатор с опечаткой или лишним пробелом — цель «висит» с нулём. Сверять с goals.md посимвольно.
- Цель заведена до привязки счётчика к кампании — статистика в Директе по ней появится только со следующего дня.
- Цели считаются с момента заведения: задним числом статистики не будет.
