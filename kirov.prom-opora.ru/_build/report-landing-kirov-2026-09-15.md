# Отчёт: одностраничник kirov.prom-opora.ru

Дата: 2026-09-15
Основа: архивная копия site-backup-html (главная страница prom-opora.ru от 2026-09-14).

## Что сделано

### Страница
- index.html собран из архивной копии главной страницы; визуальная структура сохранена полностью (шапки, слайдер, все 19 секций, модалки, подвал).
- HTML: 242 КБ → 158 КБ (inline-стили 46,6 → 16 КБ после дедупликации и чистки).

### Скрипты
- Удалён стек корзины minishop3 (17 файлов), formit, iziToast, счётчик Метрики основного сайта, Callibri, все связанные inline-скрипты и пустой счётчик корзины в шапке.
- Осталось 4 рабочих скрипта: uikit.min.js (143 КБ), uikit-icons.min.js (67 КБ), theme.js, custom.js (12 КБ — логика слайдера и ленивых карт).
- В конец страницы встроен скрипт целей: константа YM_ID = 'YM_COUNTER_ID' (заменить при подключении счётчика), делегирование кликов по data-goal, цель form_submit при отправке форм, уведомление «Заявка отправлена» при ?form=ok.

### Ссылки
- Все внутренние ссылки переписаны на https://prom-opora.ru/<адрес>. Адреса взяты из mapping.txt архива — на живом сайте они без .html (файл katalog.html → prom-opora.ru/katalog).
- Проверка: 133 ссылки на основной сайт, все существуют в mapping.txt; битых локальных путей 0.
- Форма поиска отправляет GET на prom-opora.ru/search.
- Ссылки логотипа и якоря ведут на сам лендинг.

### Цели Метрики
- 47 уникальных целей: 46 по ссылкам (одна цель на адрес, повторы делят цель) + form_submit на все формы. Размечено 172 атрибута data-goal.
- Отдельные цели: go_tel, go_email, go_whatsapp, go_viber, go_telegram, go_yamaps.
- Перечень для заведения в Метрике: _build/goals.csv (CSV с ; разделителем) и _build/goals.md (таблица).
- В Метрике завести цели типа «JavaScript-событие» с этими идентификаторами; на странице заменить YM_ID в index.html на ID счётчика.

### Формы
- 5 форм (reward, callback, pricelist, question, subscribe) отправляются на form-handler.php.
- form-handler.php: журнал заявки в claims.csv (CP1251, ; разделитель, открывается в Excel), письмо на [адрес получателя заявок], From: [адрес отправителя писем] (обе настройки — константы в начале файла), honeypot-поле website от спама, очистка и ограничение ввода, возврат на страницу с подтверждением.
- .htaccess закрывает claims.csv от скачивания по прямому адресу.
- Синтаксис PHP локально не проверялся (php не установлен) — проверить после размещения: php -l form-handler.php и тестовую отправку.

### Картинки
- 101 растровый файл конвертирован в webp (Pillow, качество 80, максимум 1600px по ширине), ссылки переписаны (src, data-bg, preload). Оригиналы jpeg остались на диске неиспользуемыми — не удалял (граница), удалить при размещении.
- Логотипы и favicon не тронуты.
- Экономия 5,9 МБ: фоновые слайдера каталога 1,2–1,4 МБ → 61–168 КБ.
- Не сконвертирован 1 файл: upload/works/catalog-trybchatye-silovye-06.jpeg — повреждён (и в архиве, вероятно, и на живом сайте). Ссылка оставлена как в источнике.

### CSS
- custom.css: 1 565 КБ → 37 КБ. В исходнике файл был склеен из 5–7 дублирующихся копий стилей с битыми скобками (~1100 незакрытых фигурных скобок). Разобран через tinycss2, правила дедуплицированы, удалены корзинные/чужие блоки (woocommerce, yith, xoo, ms3, wpc, sisea, antidrone и пр.).
- fa.all.min.css: убраны @font-face с CDN ka-f.fontawesome.com, шрифты локальные (inc/webfonts).
- theme-child.css оставлен как есть (493 КБ) — интерфейсные стили UIkit, чистка рискована.
- Слайдер home-slider: стили на месте; починены 4 битых атрибута style из-за дефекта экранирования кавычек живого сайта (фон слайда на живом сайте держится только за счёт скрипта).
- Шрифт Montserrat локальный (inc/fonts), внешние запросы шрифтов не нужны.

## Что требует внимания
1. Заменить YM_ID в index.html после подключения счётчика Метрики.
2. Завести 47 целей в Метрике по _build/goals.csv (тип «JavaScript-событие»).
3. После размещения: php -l form-handler.php, тестовая заявка (письмо + строка в claims.csv), проверить подпись SPF для [адрес отправителя писем].
4. Удалить неиспользуемые jpeg-оригиналы на хостинге (сам не удалял).
5. Повреждённый catalog-trybchatye-silovye-06.jpeg — сверить с живым сайтом, при необходимости заменить на рабочую версию.
6. Визуальная сверка с архивом по секциям (первый экран, каталог, формы, модалки) — делаем вместе.
7. Не сконвертированный тяжёлый раздел upload/works можно пересжать сильнее (качество 72–75) при желании — запас по весу ~1,5–2 МБ.
