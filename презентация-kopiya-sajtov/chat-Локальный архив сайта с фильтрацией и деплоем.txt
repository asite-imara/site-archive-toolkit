### 📑 Структура презентации (Послайдовый план)

#### Слайд 1: Титульный
*   **Заголовок:** Превращаем тяжелый CMS в молниеносный статический E-commerce.
*   **Подзаголовок:** Презентация AI-скилла для Claude: от архивации до автодеплоя.
*   **Визуал:** Иконка тяжелого сервера (CMS), которая через «воронку» AI превращается в легкое перышко (статика) с корзиной покупок.

#### Слайд 2: Боль (Зачем мы вообще это делаем?)
*   **Тезисы:**
    *   CMS-сайты (особенно с плагинами) — это «кладбище» мертвого кода, лишнего JS и CSS.
    *   Низкая скорость = потеря конверсии и плохие Core Web Vitals.
    *   Уязвимость: базы данных и админки постоянно взламывают.
    *   Ручная миграция и «прикручивание» форм/фильтров к статике занимает недели.
*   **Визуал:** Скриншот GTmetrix/PageSpeed с красными зонами и кучей иконок взломанных/устаревших плагинов.

#### Слайд 3: Концепция скилла (Что он делает?)
*   **Тезис:** Мы создали для Claude навык, который работает как **автоматическая фабрика по пересборке сайтов**.
*   **Формула:** `URL живого сайта` ➡️ `AI-обработка` ➡️ `Готовый статический магазин на хостинге`.
*   **Ключевая фишка:** Это не просто парсер. Это интеллектуальный рефакторинг с внедрением бэкенд-логики (почта, фильтры) в статику.

#### Слайд 4: Этап 1. Глубокая архивация и «Хирургия»
*   **Что делает скилл:**
    *   Создает 100% локальный HTML-архив (включая вложенные страницы и ассеты).
    *   **Умная чистка:** Находит и удаляет следы движка (например, `wp-content`), мусорные скрипты аналитики, тяжелые CSS-фреймворки от плагинов.
    *   Убирает неиспользуемые классы (Dead Code Elimination).
*   **Визуал:** До/После. Слева — «грязный» HTML с кучей `div` и инлайн-стилей. Справа — чистый, семантичный код.

#### Слайд 5: Этап 2. Реструктуризация URL и CSS-атомизация
*   **Что делает скилл:**
    *   **Смена URL-схемы:** Автоматический реврайт ссылок (убираем `.html`, `.php`, настраиваем ЧПУ).
    *   **Уровневая перекомпоновка CSS:** Скилл анализирует DOM и разбивает стили на 3 уровня:
        1.  *Critical CSS* (вшивается в `<head>` для мгновенного рендера).
        2.  *Main CSS* (базовые стили сайта).
        3.  *Page-specific CSS* (уникальные стили конкретной страницы, подгружаются лениво).
*   **Визуал:** Схема-пирог или слои, показывающая, как CSS разделяется для ускорения First Contentful Paint (FCP).

#### Слайд 6: Этап 3. «Оживление» статики (E-commerce фичи)
*   **Проблема:** Статика не имеет бэкенда. Как сделать корзину и фильтры?
*   **Решение скилла:**
    *   **Фильтрация товаров:** AI генерирует легкий JSON-массив товаров и пишет нативный JS-фильтр (без тяжелых библиотек) для поиска и сортировки на лету.
    *   **Почтовый сервис:** Интеграция API (например, SendGrid, Formspree или кастомный webhook). Скрипт собирает данные из корзины/формы и отправляет их на email менеджера в красивом HTML-формате.
*   **Визуал:** GIF-ка или схема: Пользователь кликает "Купить" ➡️ JS собирает данные ➡️ API отправляет письмо ➡️ Владелец получает заказ.

#### Слайд 7: Этап 4. Автодеплой
*   **Что делает скилл:**
    *   Финальная сборка (минификация HTML/CSS/JS, оптимизация картинок).
    *   Автоматический пуш на хостинг (через CLI, API хостинга, GitHub Actions или FTP/SSH).
*   **Визуал:** Логотипы хостингов (Netlify, Vercel, Cloudflare Pages, Timeweb и т.д.) со значком «Deployed».

#### Слайд 8: Архитектура под капотом (Для технарей)
*   Как именно Claude это делает?
    *   Использование AST (Abstract Syntax Tree) для безопасного парсинга и изменения CSS/HTML.
    *   Генерация контекстных промптов для создания JS-логики фильтров.
    *   Работа с DOM-деревом для точечного удаления мусорных классов.
*   **Визуал:** Блок-схема пайплайна (Скрипт-раннер ➡️ Claude API ➡️ Модификация файлов ➡️ CI/CD).

#### Слайд 9: Бизнес-метрики и Выгоды (ROI)
*   **Скорость:** Сокращение времени миграции/редизайна с *недель* до *часов*.
*   **Performance:** Гарантированный зеленый Zen/PageSpeed (95-100 баллов) за счет Critical CSS и отсутствия мусора.
*   **Безопасность:** Нет базы данных — нет SQL-инъекций, нет взломов через уязвимые плагины.
*   **Экономия:** Дешевый статический хостинг вместо дорогих VPS для PHP/MySQL.

#### Слайд 10: Целевая аудитория (Кому это продавать/использовать?)
1.  **Веб-студии:** Массовый перенос клиентов с WordPress на статику.
2.  **SEO-специалисты:** Ускорение сайтов для вывода в ТОП.
3.  **Фрилансеры:** Создание лендингов и каталогов «под ключ» за один вечер.

### 🎨 Идеи для визуала и метафор (Чтобы оживить выступление)

1.  **Метафора «Ремонт квартиры»:** 
    *   *CMS-сайт* — это квартира, которую годами заставляли хламом (плагины, темы). 
    *   *Ваш скилл* — это команда клинеров и дизайнеров, которые за одну ночь выносят мусор, переклеивают обои (CSS), меняют замки (URL) и устанавливают умный домофон (почтовый API).
2.  **Метафора «Тюнинг автомобиля»:**
    *   Мы берем тяжелый грузовик (CMS), снимаем с него броню (лишние скрипты), меняем двигатель на электрический (Static + JS) и оставляем только нужные опции (корзина, фильтры).
3.  **Визуализация CSS:**
    *   Покажите график загрузки. Обычный сайт ждет, пока загрузится весь CSS. Ваш сайт рендерит *Critical CSS* за миллисекунды. Это всегда вызывает вау-эффект у фронтендеров и SEO.

### 🛠 Советы по подготовке
*   **Подготовьте «Паспорт проекта»:** Заранее возьмите какой-нибудь тяжелый сайт (например, на OpenCart или WP) и прогоните его через скилл. Замеры PageSpeed Insights **ДО** и **ПОСЛЕ** будут вашим главным козырем.
*   **Акцент на AI:** Подчеркните, что Claude здесь выступает не просто как генератор текста, а как *интеллектуальный анализатор кода*, который понимает контекст (отличает нужный класс кнопки от мусорного класса плагина).
*   **Безопасность данных:** Обязательно упомяните, как скилл обрабатывает данные для корзины (например, что используется безопасный API, а не хардкод паролей в JS).
